# 📚 FocusFlow – Smart Study Planner

FocusFlow is a productivity-focused study planner built with HTML, CSS, and JavaScript. It helps students organize study tasks, track progress, and stay focused using a built-in Pomodoro-style timer.

The application combines task management and time management in a simple and user-friendly interface, making it easier to plan study sessions and maintain consistency.

---

## 🚀 Features

### 📖 Study Task Management
- Add study subjects
- Set study duration for each subject
- View all planned study tasks
- Mark tasks as completed
- Delete tasks
- Reset all tasks for a new study day

### 📊 Progress Tracking
- Track total tasks
- Track completed tasks
- Track remaining tasks
- Automatic progress updates

### ⏳ Focus Timer
- Start study sessions
- Pause active sessions
- Reset timer
- Automatic countdown
- Automatic break session after focus time ends
- Visual timer updates in real time

### 🎨 User Interface
- Clean and modern design
- Responsive layout
- Interactive buttons and animations
- User-friendly experience

### 😏 Fun Extras
- Funny notifications
- Roast-style messages
- Interactive confirmations

## ⚙️ How It Works

### 1. Add a Subject
Enter:
- Subject Name
- Study Duration

Click **Add Subject** to add it to your study plan.

---

### 2. Manage Tasks

Each task contains:

- Subject Name
- Duration
- Status

Available actions:

- ✅ Done
- 🗑 Delete

---

### 3. Track Progress

FocusFlow automatically calculates:

```text
Total Tasks
Completed Tasks
Remaining Tasks
```

and updates the statistics whenever a task is completed or deleted.

---

### 4. Focus Session

Press **Start** to begin a study session.

The timer:

- Counts down automatically
- Can be paused
- Can be reset at any time

When the focus session ends:

```text
Study Session Complete 🎉
```

an automatic break timer begins.

---

### 5. Break Session

After the study session:

- Break timer starts automatically
- Countdown is displayed on screen
- User is notified when the break ends
